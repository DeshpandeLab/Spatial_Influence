FunCN (Functional Cellular Neighborhood) tutorial

Introduction

Why we developed FunCN?
We developed FunCN to overcome the limitations of conventional neighborhood analysis methods such as KNN approach. The traditional methods rely on fixed boundaries, assigning equal weights to all neighboring cells within a cutoff distance, which can obscure the nuanced influence of spatial proximity. In reality, cellular interactions are distance-dependent, where closer cells exert stronger biological effects than those farther away. To address this, FunCN quantifies cellular influence through a continuous, distance-weighted representation that captures the gradual decay of interaction strength across spatial scales.

RESOURCES Cho, Y., Lee, J.W., Shin, S.M., Hernandez, A.G., Yuan, X., Schneider, J., Hooper, J.E., Wood, L.D., Jaffee, E.M., Deshpande, A. and Ho, W.J., 2025. Modeling cellular influence delineates functionally relevant cellular neighborhoods in primary and metastatic pancreatic ductal adenocarcinoma. bioRxiv, pp.2025-06. doi: https://doi.org/10.1101/2025.06.12.659314

Apply FunCN function

Description
Computes smoothed, leave-one-out kernel weights for each point, grouped by cell-type marks.

Requirements Input expr must contain:

  • x_col: x-coordinates
  • y_col: y-coordinates
  • celltype_col: cell type (mark)

Multi-sample data
If there is multi-sample data in one data frame:

  • Set multisample = TRUE
  • Add sample_col = "sample_col_name"

Smoothing kernels

  • A character string specifying the kernel
  • spatstat smooth function Options: "gaussian", "epanechnikov", "quartic", "disc"

Compare the FunCN score with KNN

get_neighbor_props <- function(df, k = 10, label_col = "label", xy_cols = c("x","y"), all_labels = NULL) {
  # run kNN
  knn_idx <- get.knn(df[, xy_cols], k = k)$nn.index
  # pull labels as vector
  labels_vec <- df[[label_col]]
  # map neighbor indices -> labels
  knn_labels <- matrix(labels_vec[knn_idx],
                       nrow = nrow(knn_idx),
                       ncol = ncol(knn_idx))
  
  # count label frequency per row
  freq_mat <- t(apply(knn_labels, 1, function(neigh_labels) {
    tab <- table(factor(neigh_labels, levels = all_labels))
    as.numeric(tab)
  }))
  colnames(freq_mat) <- all_labels
  
  # convert to proportions
  prop_mat <- as.data.frame(freq_mat/k)
  # set rownames: "<rownames>:<label>"
  rownames(prop_mat) <- paste0(rownames(df), ":", df[[label_col]])
  return(prop_mat)
}

# define labels
all_labels <- unique(c(equidist_pts$label, radial_pts$label))

to_long <- function(df, method_name, sample_name) {
  df %>%
    as.data.frame() %>%
    pivot_longer(
      cols = c("A","B","C","D"),
      names_to = "label",
      values_to = "value"
    ) %>%
    mutate(
      method = method_name,
      sample = sample_name
    )
}
